Software Design & Engineering

The original CS 360 application was redesigned with clearer navigation, dedicated account creation and sign-in, stronger password requirements, user profiles, and a progress experience built around the user’s goals.

  • Salted PBKDF2-HMAC-SHA256 password hashing
  • Login lockout behavior and input validation
  • Profile management and goal settings
  • Separated responsibilities for maintainable code

02

Algorithms & Data Structures

A dedicated analysis layer converts chronological weight entries into understandable progress measures without presenting predictions when the available data is unreliable.

  • BMI, weekly average, and progress percentage
  • Trend analysis and goal-date estimation
  • Efficient seven-day moving window
  • Custom chart, friendly reminders, and unit tests
View artifact ↗
03

Databases

The SQLite database was expanded into a relational health journal that preserves existing records while supporting richer profiles, BMI history, calorie goals, calorie logs, and date-based search.

  • Data-preserving version 3 schema migration
  • Foreign keys, uniqueness rules, and cascading deletes
  • Transactional CRUD and parameterized queries
  • Filtering, validation, and integrity testing
